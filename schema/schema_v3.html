↗ v3 Changes
− artifact_dependencies removed. Dependency graph tracking not required for this tool.
+ tools lookup table added. Canonical registry of build tools with controlled vocabulary — enforces spelling consistency and stores source/ownership metadata.
+ artifact_tools added. Links each artifact to the tools used to build it. Each tool carries its own git version. Unique constraint on (artifact_id, tool_id) prevents duplicates.

Key Relationships — Artifact Layer focus
RelationshipCardinalityConstraint / Note
tools.name unique Controlled vocabulary — only way to introduce a tool name into the system
tools → artifact_tools 1 → M One tool can appear across many artifact builds at different versions
artifacts → artifact_tools 1 → M One artifact was built with potentially many tools
artifact_tools (artifact_id, tool_id) unique A tool cannot appear twice on the same artifact — prevents duplicates
artifacts → artifact_files 1 → M Single-file: 1 row. Multi-file: N rows with independent digests
tools.owned_by_team_id → teams N → 1 Internal tools are owned by a team; external tools leave this null
artifact_dependencies — Removed. Dependency graph tracking out of scope.
